# Decime UY — Technical Brief для разработки и установки на Android-телефон

**Версия:** 0.2  
**Дата:** 2026-05-31  
**Цель:** создать рабочий MVP для личного теста на Android-телефоне с Share-to-Reply Flow  
**Основной сценарий:** WhatsApp/мессенджер → Share в Decime → перевод/ответ → Share обратно

---

## 1. Рекомендуемая техническая стратегия

Для MVP нужно разделить продукт на два слоя:

1. **Decime Core** — backend + AI logic + database + web UI.
2. **Mobile Share Shell** — Android-слой, который позволяет удобно принимать text/audio через системный Share и отправлять результат обратно.

Рекомендуемый путь:

```text
Phase 1: Web/PWA + FastAPI backend + Supabase + OpenAI
Phase 2: Android Capacitor wrapper for installation and share testing
Phase 3: custom native Android intent handler if Capacitor/PWA share is insufficient
Phase 4: VM deploy + auth (Twilio/Meta connector — out of scope, see docs/out_of_scope.md)
```

Причина: Android официально поддерживает передачу данных между приложениями через Sharesheet/intent resolver, а приложение-получатель может зарегистрировать MIME-типы через `intent-filter`. Для отправки наружу Android использует `ACTION_SEND` с `EXTRA_TEXT` для текста и `EXTRA_STREAM` для файлов. PWA тоже может использовать Web Share / Share Target, но поддержка Share Target ограниченная и экспериментальная, поэтому для телефона лучше сразу планировать Android wrapper.

## 4. Core backend services

### 4.1. API endpoints

#### `POST /api/incoming/understand-text`

Input:

```json
{
  "source_text": "Podés pasar mañana después de las 10?",
  "source_language": "es",
  "target_explanation_language": "ru",
  "locale_variant": "es-UY-montevideo",
  "context": {
    "channel": "whatsapp_text",
    "situation": "unknown"
  }
}
```

Output:

```json
{
  "original_text": "Podés pasar mañana después de las 10?",
  "translation_ru": "Ты можешь зайти завтра после 10?",
  "translation_en": "Can you come tomorrow after 10?",
  "tone_notes_ru": [],
  "uncertain_parts": [],
  "detected_locale": "es-UY-or-rioplatense",
  "confidence": 0.85
}
```

**UX rule:** `translation_ru` / `translation_en` — единственный основной текст понимания. Не возвращать отдельное поле «meaning summary», которое перефразирует перевод. `tone_notes_ru` и `uncertain_parts` — только если добавляют **новую** информацию (тон, сомнения STT), не дублируют перевод.

#### `POST /api/incoming/transcribe-audio`

Input:


```json
  "translation_en": "Well, if you want, I can send it to you tomorrow.",

  "uncertain_parts": [],
```

## 5. Database schema draft

### `messages`

```sql
create table messages (
  id uuid primary key default gen_random_uuid(),
  user_id uuid,
  source_type text not null,
  -- whatsapp_text / whatsapp_audio / user_text / user_voice / pasted_text / uploaded_audio
  source_language text,
  original_text text,
  transcript text,
  translation_ru text,
  translation_en text,
  tone_notes_ru jsonb default '[]',
  uncertain_parts jsonb default '[]',
  audio_file_id uuid,
  created_at timestamptz default now()
);
```

### `reply_requests`

```sql
create table reply_requests (
  id uuid primary key default gen_random_uuid(),
  user_id uuid,
  incoming_message_id uuid references messages(id),
  user_reply_intent text not null,
  user_reply_language text not null,
  target_locale text not null default 'es-UY-montevideo',
  channel text not null default 'whatsapp_text',
  tone text not null default 'neutral_friendly',
  level text default 'A2-friendly',
  created_at timestamptz default now()
);
```

### `reply_outputs`

```sql
create table reply_outputs (
  id uuid primary key default gen_random_uuid(),
  reply_request_id uuid references reply_requests(id),
  recommended_reply text not null,
  short_reply text,
  more_polite_reply text,
  simple_a2_reply text,
  notes_ru jsonb,
  raw_json jsonb,
  audio_file_id uuid,
  created_at timestamptz default now()
);
```

### `audio_files`

```sql
create table audio_files (
  id uuid primary key default gen_random_uuid(),
  user_id uuid,
  storage_path text not null,
  mime_type text,
  duration_ms int,
  source_type text,
  created_at timestamptz default now()
);
```

### `training_lists`

```sql
create table training_lists (
  id uuid primary key default gen_random_uuid(),
  user_id uuid,
  name text not null,
  source text not null default 'user',
  locale_variant text not null default 'es-UY-montevideo',
  created_at timestamptz default now()
);
```

### `training_items`

```sql
create table training_items (
  id uuid primary key default gen_random_uuid(),
  user_id uuid,
  list_id uuid references training_lists(id),
  item_type text not null,
  -- noun / adjective / verb_form / verb_infinitive

  surface_text text not null,
  display_text text not null,
  lemma text,
  locale_variant text not null default 'es-UY-montevideo',

  translations_ru jsonb not null,
  translations_en jsonb,
  context_translation_ru text,
  context_translation_en text,

  grammar jsonb,
  governance jsonb,

  example_es text,
  example_ru text,
  example_en text,

  audio_file_id uuid references audio_files(id),

  source_message_id uuid references messages(id),
  source_reply_output_id uuid references reply_outputs(id),
  source_type text,

  status text not null default 'approved',
  -- candidate / approved / skipped / known

  next_review_at timestamptz,
  review_stage int default 0,
  created_at timestamptz default now()
);
```

### Dedup key

Create a canonical key in code:

```text
locale_variant + item_type + surface_text + lemma + grammar_signature + primary_translation
```

Examples:

```text
es-UY|noun|la factura|factura|feminine_singular|счёт
es-UY|verb_form|podés|poder|vos_present_indicativo_2sg|ты можешь
es-UY|verb_infinitive|mandar|mandar|infinitive|отправлять
```

## 6. AI prompt contracts

### 6.1. Understand Spanish input

System role:

```text
You are Decime UY, a communication assistant for Uruguayan Spanish, defaulting to Montevideo. Translate incoming Spanish messages for a Russian- or English-speaking user. Be concise and practical. Do not over-explain grammar unless requested. Treat STT transcripts as potentially imperfect.

Important: return ONE natural translation as the main result. Do NOT add a separate meaning summary or paraphrase that repeats the same information as the translation. Only add tone_notes or uncertain_parts when they provide new information not already clear from the translation.
```

Must output JSON:

```json
{
  "original_text": "string",
  "translation_ru": "string",
  "translation_en": "string",
  "tone_notes_ru": ["string"],
  "uncertain_parts": ["string"],
  "detected_locale": "string"
}
```

Do **not** include `meaning_summary_ru` or equivalent redundant paraphrase fields.

### 6.2. Compose reply

System role:

```text
You are Decime UY, a reply composer for Uruguay/Montevideo Spanish. The user thinks in Russian or English. Generate natural, locally appropriate Spanish replies for WhatsApp or live communication. Default style: neutral, friendly, not too slangy, A2-friendly where possible. Avoid Spain-specific vocabulary and excessive Buenos Aires slang.
```

Must output JSON:

```json
{
  "locale_variant": "es-UY-montevideo",
  "recommended_reply": "string",
  "short_reply": "string",
  "more_polite_reply": "string",
  "simple_a2_reply": "string",
  "notes_ru": ["string"],
  "risk_notes_ru": ["string"]
}
```

### 6.3. Extract training candidates

System role:

```text
You extract MVP training candidates from Spanish text for an A1/A2 learner of Uruguayan Spanish. Extract only these item types: noun, adjective, verb_form, verb_infinitive. Do not extract full expressions, idioms, or sentence patterns in MVP. For nouns, include article, gender and number. For adjectives, include gender/number and basic forms. For verb forms, extract the exact observed form as its own training item, include pronoun, tense, mood, person, number, voseo flag if relevant, lemma and governance. Infinitives are separate items and must not replace observed verb forms. Provide precise Russian and English translations and contextual translation if needed.
```

Must output JSON matching `TrainingCandidateBundle`.

## 8. Android Share implementation

### 8.1. Incoming share target — ideal behavior

The app should appear in Android Sharesheet for:

```text
text/plain
text/*
audio/*
application/octet-stream as fallback for unknown shared audio
```

When content is shared into Decime:

```text
if text:
  open /quick-reply with incomingText prefilled

if audio:
  copy stream to app cache
  upload to /api/incoming/transcribe-audio
  open /quick-reply with transcript/translation
```

### 8.2. Capacitor path

Capacitor handles outgoing share well via `@capacitor/share`. Incoming share may require custom native Android code or a community plugin. Do not assume web `share_target` is enough for reliable audio.

Minimum outgoing share:

```ts
import { Share } from '@capacitor/share';

await Share.share({
  text: replyText,
  dialogTitle: 'Share reply'
});
```

For audio sharing:

```ts
await Share.share({
  files: [localAudioFileUri],
  dialogTitle: 'Share audio reply'
});
```

Capacitor docs note that file sharing is supported on iOS and Android and Android file sharing is restricted by configured file paths.

### 8.3. Native Android intent filters

If custom native handling is needed, add intent filters similar to:

```xml
<intent-filter>
    <action android:name="android.intent.action.SEND" />
    <category android:name="android.intent.category.DEFAULT" />
    <data android:mimeType="text/plain" />
</intent-filter>

<intent-filter>
    <action android:name="android.intent.action.SEND" />
    <category android:name="android.intent.category.DEFAULT" />
    <data android:mimeType="audio/*" />
</intent-filter>
```

Native handler logic:

```kotlin
when (intent?.action) {
    Intent.ACTION_SEND -> {
        val type = intent.type
        if (type == "text/plain") {
            val sharedText = intent.getStringExtra(Intent.EXTRA_TEXT)
        } else if (type?.startsWith("audio/") == true) {
            val audioUri = intent.getParcelableExtra<Uri>(Intent.EXTRA_STREAM)
        }
    }
}
```

### 8.4. Outgoing share back to WhatsApp

For text, share as `text/plain`.

For audio, share as `audio/ogg`, `audio/mpeg`, or actual generated MIME type. The user chooses WhatsApp and the recipient/chat.

Important: Decime should not auto-send messages into WhatsApp. It prepares text/audio and invokes the system share UI.

## 13. Technical risks

### WhatsApp audio sharing

Hypothesis only. Android can receive shared audio if the source app shares it, but WhatsApp behavior must be tested on the real target device.

Mitigation:

```text
manual upload
record inside Decime
manual upload / Share only (Twilio out of scope)
```

### Locale quality

Model may output generic Spanish. Mitigation:

```text
strict locale prompt
LocaleCriticUY validation step
test fixtures for Uruguay-specific wording
native speaker review later
```

### Mobile networking

Phone cannot call `localhost` on PC. Use LAN IP, ngrok, or deploy backend.

### Audio file formats

WhatsApp voice notes may use formats such as opus/ogg or other containers. Backend should accept common audio MIME types and normalize if needed.
